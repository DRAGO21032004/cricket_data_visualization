# Cricket Data Visualization Project

## Project Overview

This project aims to analyze and visualize cricket match data to uncover performance patterns and key statistics. Using **Power BI**, the project presents interactive dashboards that help fans, analysts, and enthusiasts understand game trends, player contributions, and match outcomes in a visually compelling manner.

---

## Objective

- To visualize important cricket metrics such as **top-performing players**, **run distributions**, **wicket patterns**, and **match outcomes**.
- To create an interactive dashboard that enables users to slice and analyze data by team, year, venue, and more.

---

## Dataset Used

The dataset includes match-level and player-level data such as:

- Player runs, wickets, and strike rates
- Match winners- Batting and bowling statistics

---

## Tools and Technologies

## Key Features

- Data cleaned and formatted for uniformity (player names, match results, etc.)
- Consistent date formats and missing value handling
- Measures created for calculating aggregates like:
  - Total runs by player/team
  - Average strike rate



---

## Visualizations with Power BI

- **Top Run Scorers**: Bar chart showing highest run-getters across seasons.
- **Top Wicket Takers**: Bar chart showing bowlers with highest wickets.



---

## Interactive Filters

- Year/Season
- Player
- Match outcome
